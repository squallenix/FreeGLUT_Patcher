1. EDUCATIONAL PURPOSE & NON-PROFIT STATEMENT
---------------------------------------------
This patcher tool and packaged configuration are created exclusively for
EDUCATIONAL EASE, ACADEMIC ASSISTANCE, AND STUDENT LEARNING.

Setting up FreeGLUT and OpenGL manually inside Code::Blocks and MinGW on Windows
often poses significant barriers for beginners (such as missing header files,
unmatched 32-bit/64-bit binaries, linker errors like "cannot find -lglut32",
and missing DLL runtime errors).

The sole intent of this project is to eliminate those technical barriers so
students, educators, and hobbyists can focus directly on learning computer
graphics, programming, and OpenGL concepts without frustrating setup hurdles.
