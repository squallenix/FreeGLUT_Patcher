# Contributing to FreeGLUT MinGW Patcher

Thank you for your interest in improving the **FreeGLUT & OpenGL Patcher**!

This project was built to simplify OpenGL setup for students, beginner programmers, and educators. Contributions that make the tool more reliable, accessible, or easier to use are warmly welcomed.

---

## 🎯 How You Can Help

1. **Testing on Different MinGW Distributions**:
   - Testing across Code::Blocks versions (17.12, 20.03, 25.xx).
   - Testing with custom MinGW distributions (e.g. WinLibs, MSYS2, standalone MinGW-w64).
2. **Reporting Issues**:
   - If you encounter a compiler error, missing file, or architecture problem, please [open an issue](https://github.com) with:
     - Windows OS version (Windows 10, 11, etc. - 32-bit or 64-bit).
     - Code::Blocks version.
     - MinGW GCC version (`gcc -v`).
     - Error messages or screenshots.
3. **Improving Documentation**:
   - Translations, clearer step-by-step guides, or platform troubleshooting tips.

---

## 📜 Development Guidelines

- **Zero-Dependency**: The batch and PowerShell scripts must run out of the box on default Windows installations without requiring third-party tools (Python, Node.js, etc.).
- **Educational & Non-Profit**: All contributions must align with the educational, non-profit spirit of this project.
- **Backwards Compatibility**: Must support both 32-bit and 64-bit MinGW compilers.
